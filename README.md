Todo List (Python)

A simple command-line todo list application built with Python. Tasks are organised by priority and category, and are saved to a JSON file.

Features
- Add tasks with a title, optional description, category and priority
- View all tasks, automatically sorted by priority (high, medium, low)
- Filter by category (work, study, personal)
- Mark tasks as completed
- Edit existing tasks, press Enter to keep any current value
- Delete tasks
- Summary showing total, pending and completed counts
- Persistent storage using a JSON file (tasks.json)
- Input validation for task numbers, categories and priorities

Menu of the program :

===== TODO LIST =====
1. Add task
2. View all tasks
3. Filter by category
4. Mark task as done
5. Edit task
6. Delete task
7. Summary
8. Exit

To Run : python saitodolist.py
